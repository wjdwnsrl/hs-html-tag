# HTML 태그 정리

## 1. HTML 기본 구조

| 태그 | 의미 / 용도 | 예시 |
|---|---|---|
| `<html>` | HTML 문서 전체 | `<html> ... </html>` |
| `<head>` | 문서의 정보 설정 | `<head> ... </head>` |
| `<title>` | 웹페이지 제목 | `<title>홈페이지</title>` |
| `<body>` | 실제 화면에 표시되는 내용 | `<body>내용</body>` |
| `<!DOCTYPE html>` | HTML5 문서임을 선언 | `<!DOCTYPE html>` |

---

## 2. 글자 / 문단 관련 태그

| 태그 | 의미 / 용도 | 예시 |
|---|---|---|
| `<h1>` ~ `<h6>` | 제목 | `<h1>제목</h1>` |
| `<p>` | 문단 | `<p>안녕하세요.</p>` |
| `<br>` | 줄바꿈 | `안녕<br>하세요` |
| `<hr>` | 수평선 | `<hr>` |
| `<strong>` | 중요한 내용, 굵게 표시 | `<strong>중요</strong>` |
| `<b>` | 굵게 표시 | `<b>굵은 글씨</b>` |
| `<em>` | 강조, 기울임 | `<em>강조</em>` |
| `<i>` | 기울임 | `<i>기울임</i>` |
| `<small>` | 작은 글씨 | `<small>작은 글씨</small>` |
| `<mark>` | 형광펜 효과 | `<mark>강조</mark>` |
| `<del>` | 삭제된 내용 | `<del>삭제</del>` |

---

## 3. 목록 관련 태그

| 태그 | 의미 / 용도 | 예시 |
|---|---|---|
| `<ul>` | 순서 없는 목록 | `<ul>...</ul>` |
| `<ol>` | 순서 있는 목록 | `<ol>...</ol>` |
| `<li>` | 목록의 항목 | `<li>사과</li>` |
| `<dl>` | 설명 목록 | `<dl>...</dl>` |
| `<dt>` | 설명할 항목 | `<dt>HTML</dt>` |
| `<dd>` | 항목에 대한 설명 | `<dd>웹 문서 작성 언어</dd>` |

### 예시

```html
<ul>
    <li>사과</li>
    <li>바나나</li>
    <li>포도</li>
</ul>
